# index.html Page

`website/index.html` (about 450 lines) is the whole site.
It loads Google Fonts (Playfair Display, Montserrat),
[[styles.css]], the [[EmailJS]] browser SDK from jsDelivr,
and [[script.js]] at the end of the body.

Section order and anchors are on [[Site Structure]]. All
outgoing shop links use the Zinzino referral shop
`https://www.zinzino.com/2020240904`; see [[Zinzino]].
